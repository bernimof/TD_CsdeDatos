# M9 Fundamentos de Big Data - Retail Analytics Pipeline

---

## 🇨🇱 🇪🇸 Objetivo
Este proyecto diseña e implementa un **pipeline completo de Big Data y Machine Learning** sobre datos reales de e-commerce, utilizando Apache Spark como motor distribuido. El objetivo es procesar, analizar y modelar datos masivos del marketplace brasileño Olist para generar insights accionables para el área de marketing de la empresa ficticia RetailMax.

---

## 🇺🇸 🇬🇧 Objective
This project designs and implements a **complete Big Data and Machine Learning pipeline** on real e-commerce data, using Apache Spark as the distributed engine. The goal is to process, analyze and model massive data from the Brazilian marketplace Olist to generate actionable insights for the marketing area of the fictional company RetailMax.

---

## 📁 Dataset
**Brazilian E-Commerce Public Dataset by Olist** — Kaggle  
🔗 https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

4 tablas utilizadas / 4 tables used:
- `olist_orders_dataset.csv` — 99.441 pedidos / orders
- `olist_order_items_dataset.csv` — 112.650 ítems / items
- `olist_order_reviews_dataset.csv` — 104.162 reseñas / reviews
- `olist_products_dataset.csv` — 32.951 productos / products

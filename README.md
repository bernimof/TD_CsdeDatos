# Portafolio de Ciencia de Datos 

## 🇨🇱 🇪🇸 Descripción del repositorio
Este repositorio contiene ejercicios, casos prácticos y análisis desarrollados durante el programa de **Ciencia de Datos – Talento Digital (2025–2026)**.

El objetivo principal es evidenciar competencias en análisis de datos, limpieza, transformación y manipulación de datos, utilizando herramientas ampliamente utilizadas en entornos profesionales.

# Data Science Portfolio

## 🇺🇸 🇬🇧 Repository description
This repository contains exercises, practical cases, and data analyses developed during the **Data Science Program – Talento Digital (2025–2026)**.

Its main objective is to demonstrate skills in data analysis, data cleaning, transformation, and manipulation using tools commonly applied in professional environments.


## 📁 Projects

| Module | Project | Main tools |
|--------|---------|------------|
| M3.3 | Case Analysis — Data Wrangling | Pandas, NumPy |
| M3.4 | Data Preparation & Wrangling | Pandas, NumPy |
| M4 | Exploratory Data Analysis (EDA) | Pandas, Matplotlib, Seaborn |
| M5 | Statistical Inference | SciPy, Pandas |
| M6 | Purchase Prediction — AutoPredict | Scikit-learn, Ridge, GradientBoosting |
| M7 | Customer Segmentation | K-Means, DBSCAN, Scikit-learn |
| M8 | Clothing Classifier — StyleNet | TensorFlow, CNN, Fashion-MNIST |
| M9 | Retail Analytics Pipeline — RetailMax | Apache Spark, PySpark, Spark MLlib |

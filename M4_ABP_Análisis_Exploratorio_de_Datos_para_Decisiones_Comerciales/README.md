# M4 Proyecto de Análisis Exploratorio de Datos para Decisiones Comerciales

---

## 🇨🇱 🇪🇸 Objetivo
Este proyecto tiene como objetivo realizar un análisis exploratorio de datos sobre el comportamiento de clientes de una plataforma de comercio electrónico. Se busca identificar patrones, correlaciones, y recomendaciones basadas en el comportamiento de compra.

## Pasos realizados
1. **Análisis Exploratorio de Datos (EDA)**
2. **Modelo de Regresión Lineal**
3. **Evaluación de Resultados**
4. **Generación de un informe técnico y visualizaciones exportables**.

---

## 🇺🇸 🇬🇧  Objective
This project aims to conduct an exploratory data analysis of customer behavior on an e-commerce platform. The goal is to identify patterns, correlations, and recommendations based on purchasing behavior.

## Steps Performed
1. Exploratory Data Analysis (EDA)
2. Linear Regression Model
3. Results Evaluation
4. Generation of a technical report and exportable visualizations

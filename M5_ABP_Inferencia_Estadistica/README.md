# M5 Proyecto Inferencia Estadística - Análisis Estadístico sobre Hábitos Saludables en Universitarios

---

## 🇨🇱 🇪🇸 Objetivo
Este proyecto analiza los hábitos de los estudiantes universitarios en relación con el **déficit de sueño** y **actividad física**. Utilizando métodos estadísticos, se evaluó el cumplimiento de las recomendaciones de sueño y ejercicio a partir de un dataset de 200 estudiantes.

## Métodos
a) **Simulación** del **Teorema del Límite Central** para verificar la aproximación a la normalidad de las **proporciones muestrales**.

b) **Pruebas de hipótesis**:
  - Para **media** de **Horas de Sueño**: H₀: μ = 7, H₁: μ < 7.
  - Para **proporción** de estudiantes activos: H₀: p = 0.50, H₁: p < 0.50.

c) **Cálculo de intervalos de confianza** para las medias de las variables clave con niveles de confianza del 90%, 95% y 99%.


---

## 🇺🇸 🇬🇧  Objective
This project analyzes the habits of university students in relation to **sleep deficit** and **physical activity**. Using statistical methods, compliance with sleep and exercise recommendations was evaluated based on a dataset of 200 students.

## Methods
a) **Simulation** of the **Central Limit Theorem** to verify the approximation to normality of the **sample proportions**.

b) **Hypothesis tests**:
- For the **mean** of **Hours of Sleep**: H₀: μ = 7, H₁: μ < 7.
- For the **proportion** of active students: H₀: p = 0.50, H₁: p < 0.50.

c) **Calculation of confidence intervals** for the means of the key variables with confidence levels of 90%, 95% and 99%.
